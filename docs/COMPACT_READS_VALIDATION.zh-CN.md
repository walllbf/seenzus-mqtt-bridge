# 精简读取本地验证（2026-10-05）

关联：Seenzus #2045。输入均为合成样本，不含家庭数据、凭据或生产连接。

Bridge 基线 `a0c8e0bfc6578245034fbfeaac55d0bc033630b2`；应用基线 `fffdd9ed7f3bbcd3e881000452ed7dab03871a0d`。

## 测量口径

- 每实体含中文名称（240 个汉字）及嵌套数组，原始状态时间固定。
- 预算固定 1,048,576 字节；统计实际收到的完整 MQTT PUBLISH，包括 UTF-8 topic/payload、QoS packet ID 与长度头。TLS/WebSocket 外层不属于 MQTT Broker 报文上限。
- TCP 和本地 TLS/WSS 使用真实 aiomqtt/Paho，测试 Broker 逐包断言预算。额外 QoS 1 栅栏只用于确认收齐，未计入业务字节。
- 内存为 Python tracemalloc 峰值，包含发布与抓取线程；解析为一次 JSON 解码全部实际报文；均为单次样本观测，不是稳定性能承诺。

应用：`npm run check`；`npm test -- server/sources/runtime/__tests__/mqttCompactReads.test.ts server/sources/runtime/__tests__/mqttBridge.test.ts server/sources/runtime/__tests__/sourceRuntime.test.ts`。
