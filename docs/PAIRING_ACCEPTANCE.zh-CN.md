## 首次配对与同步

- [ ] 安装候选包并重启 HA，确认集成加载成功；依赖版本符合当前 Core 的运行时约束。
- [ ] 在测试实例添加集成、发起快速配对，在 App 完成授权并回跳 HA；确认 entry 成功保存，App 与 HA 中的桥身份对应。
- [ ] 确认使用约定的 WSS 地址/path，Broker 认证与命令订阅成功，catalog、当前实体状态及服务能力读取可用。
- [ ] 对照测试实体集合与完整属性检查同步结果；配对界面成功或收到一条 State 不作为全部同步完成的证明。
- [ ] 如果 Broker 已配置为 2 MiB，将「配置 → MQTT 连接设置」设为 `2048` KiB；检查状态实体的 `mqtt_max_packet_size=2097152`，配对凭据与桥身份保持不变。

## 重启、断网与限额

- [ ] HA 重启后无需重新授权，原测试配对自动重连并恢复目录、状态和服务读取。
- [ ] 暂停测试实例网络后恢复，检查自动重连、同步及历史补录；记录断线次数、原因和恢复时间，不使用生产 Broker 的重启作为测试手段。
- [ ] 在预先约定的稳定时段内观察连接起点、消息计数、积压与日志，并写明具体时长；持续在线与完整同步分别判定。
- [ ] 在受控数据中验证超过 1 MiB、低于 2 MiB 的不可压缩响应：预算与 Broker 均为 2 MiB 时完整返回，下一条命令仍正常。
- [ ] 单条实体超过本地预算时出现明确实体/来源/大小错误，其他正常实体继续传输；漏送、413 和部分同步不能标记为完整成功。
- [ ] 启动 catalog 超限时状态显示错误并停止重复连接，在线声明撤回；修正数据或已确认的预算并重载后恢复。提高桥预算不能超过 Broker 实际限制。
- [ ] 两个独立测试配置项同时在线且不相互顶下线；重启同一配置项后 client ID 保持稳定。复制同一个 entry_id 不属于两个独立身份。
